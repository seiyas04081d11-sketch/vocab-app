# 英単語暗記アプリ（覚えられない単語用）

- 目的: 英単語帳で覚えられない単語を、スマホで回して覚える。個人利用。
- 形式: 2つのパートに分ける（2026-11-24 v6）
  - STEP 1「覚える」: 新しい単語を答えを全部見ながら覚える。自分の覚え方（語呂・どこで出会ったか）をその場で書ける。「覚えた」で演習へ回る。
  - STEP 2「演習」: 思い出すカード＋間隔反復（下の流れ）。
- もっとやる（何回でも）: ＋10語覚える／今日の単語を見直す／苦手・今日の単語・ランダムを演習（練習扱いで予定は変えず、間違えた単語だけすぐ復習へ）。
- やる気の維持: その日の「覚える」「演習」を両方0にすると達成。連続日数・最高記録・直近7日をホームに表示。
- 見た目: 色テーマ10種・フォント3種（ホームの「見た目」、端末ごとに保存）。
- 配布: PWA（Safariの「ホーム画面に追加」）。App Storeは使わない。
- 著作権: 書籍の中身は同梱しない。data/sample.csv は自作の30語。本物の単語はCSVで各端末に読み込む。

## 演習の1枚の流れ
1. 単語を見て意味を思い出す（必要ならヒント: 英語の例文 → 和訳）
2. 「わかる」→ 答えを見て「違った / あいまい / 合ってた」、「わからない」→ そのまま「だめ」
3. 補正ルール: ヒントを使った、または 1.5秒未満で「わかる」を押した場合、「合ってた」でも「あやしい」で記録

## 次に出る日
- だめ: 4枚後にもう一度（間隔はリセット）
- あやしい: 1日後（以後は間隔×1.2）
- OK: 3日後（以後は間隔×2.5）
- 「覚える」に出す新しい単語は1日10語まで（設定で変更可）

## CSVの列
no, word, pos, meaning, cue, example_en, example_ja, note, related, memo, ja_note
- no はカードごとに一意（多義語は 0565-1, 0565-2 のように分ける）
- cue = 表面に出す短いフレーズ（多義語のみ）、memo = 覚え方、ja_note = 難しい日本語の説明

## 公開
- GitHub Pages で公開。private/（自分の単語データ）と .claude/ は .gitignore で除外。
- iPhone ではホーム画面のアイコンから開いて CSV を読み込む（Safari とホーム画面アプリは保存場所が別）。

## 仕様メモ（2026-11-24）
- **日本語の補足**（実装済み）: 訳語そのものが難しい・日常で使わない日本語（例: 恣意的、精査）には、日本語の説明を付ける（列 `ja_note`）。
- **多品詞・多義語は別カード**（実装済み）: address（動・取り組む）／address（名・住所）のように、意味ごとに1枚。読み飛ばし防止のため。
  - 表面には品詞と短いフレーズ（例: address the issue）を出し、どの意味を答えるか分かるようにする。答え面に他の意味を小さく並べる。
- **印象に残る仕掛け**（メインユーザーは「模試で出た」「いい語呂が見つかった」など印象的になった単語を覚える）:
  - 覚え方欄（語呂・語源）をCSV作成時に用意（済）。アプリ内で自分の覚え方を書ける（済、CSVとは別に保存）。
  - 「どこで出会ったか」も同じ自分の覚え方欄に書ける（済）。
  - 例文は無難なものより、場面が浮かぶ印象的なものを優先。
